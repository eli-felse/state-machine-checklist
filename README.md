# D | Changes: Add test cases for unreachable states and verify dark mode exports.

An interactive tool for designing state machines: add states, events, and transitions, mark states as terminal, and instantly get a checklist covering implementation tasks, naming convention guidelines, and design best practices, plus automated checks for issues like unreachable states, unused events, and non-terminal states with no outgoing transitions. Includes a light/dark mode toggle. Checklists can be saved, reloaded, and downloaded as a standalone, self-contained HTML file that always uses the dark theme. Includes a dependency-free Node test suite (tests/run-tests.js) covering unreachable-state detection and dark-theme HTML exports.
